# F16 后台数据查询规范提示词（给后台/管理端把「查数据」这件事做对）

> 用途：宿主项目里有后台查询页（订单/工单/财务/运营看板等），条件多、查得慢、口径靠嘴解释、
> 看板只能看不能点。按下面这段发给执行者（人或 AI），先回开工表再动手。
> 想先看效果：模板仓库 `素材库/后台数据查询规范/`（实现方案 / 环境要求 / 参考来源 + 代码镜像），
> 示例 App 素材库第三分区「数据查询规范 · 5」可逐条操作。

```
按模板仓库 yz8023/ui 的 F16（后台数据查询规范，条目 Q01–Q05）改造我的后台查询页：
【宿主项目技术栈：语言/UI 体系/minSdk/是否已有 Compose 或 FlowRow 等价能力】
【要改的页面与文件：______】
【真实数据源与单次查询耗时：______（决定要不要开批量提交）】
【数据保留期：______ 天（决定哪些时间档位要置灰）】
【维度与负责人对应关系：______（决定下钻后转交给谁）】

先读该仓库 AGENTS.md、docs/功能逐项手册.md 的 F16 节、素材库/后台数据查询规范/实现方案.md，
然后回开工表（目标编号 / 宿主技术栈 / 选定路线 / 将新增修改的文件逐个列全 / 明确不做的事）等我确认，
确认前禁止写代码。

四刀逐项要求（与模板实现口径一致，缺一刀算未完成）：

1. Q01 筛选分层与批量提交
   - 条件按使用频率分层：高频（时间、状态、部门/主体）常显，低频（渠道、金额区间、仅看异常等）
     收进「更多筛选」；折叠时若有已选值，入口必须显示计数徽标（如「更多筛选 ·2」）。
   - 单次查询 >300ms 或条件互相牵制时启用批量提交：改条件只写「待生效草稿」，不请求；
     出现「查询（n 项待生效）」按钮，点了才发一次请求；请求期间按钮 loading 且禁止重复提交。
   - 草稿与生效必须双状态分离：查询函数在调用点即时读取草稿，不要把草稿提成渲染期的常量再传进去
     （模板踩过这个坑：删条件后重查会用到旧值）。
   - 结果区回显本次生效条件 + 命中条数 + 耗时 + 累计请求次数；未按查询前明示「结果仍是上次查询」。

2. Q02 时间区间写明起止
   - 快捷档位（今日/昨日/近7日/近30日/本季度/近一年）每个写明真实起止日期，
     如「近7日 10-26 ~ 11-01」，并标注口径「含首尾，共 n 天」；禁止只写「近7天」。
   - 超出数据保留期的档位置灰不可点，就地给原因与最早可查日期，不要点了才报错。
   - 自定义起止做校验：起 > 止 禁止查询并说明；止 > 今天钳制到今天。
   - 本季度按季度首日实算，不要写死天数。

3. Q03 已选条件标签聚合
   - 同维度全选 → 一个标签「全部部门 · 20」；同维度已选 > 阈值（模板默认 3）→ 一个标签「部门 · n」，
     点按可展开逐项查看；≤ 阈值 → 逐个显示。
   - 每个标签带独立删除（×），删除即回退筛选并重算命中数；提供「清空全部条件」。
   - 标签的「点按（展开/编辑）」与「删除（回退筛选）」是两个动作，不许合并成一个。
   - 标签区限高（模板 2 行），超出用聚合标签或「+n」承接，条件栏不许把结果区挤出首屏。

4. Q04 看板下钻与明细转交
   - 每根柱子/扇区可点，点选后详情区只呈现该切片：标题写「渠道 · 直播」，
     金额/笔数/占比与明细同步过滤；再点一次取消选中。
   - 未选中时给可操作引导空态（「点任意一根柱子，这里只看这块」），不要只写「暂无数据」。
   - 切换聚合维度时清空已选切片与导出状态，并提示原因。
   - 明细可导出：带表头 CSV，回显行数与体积，展示前几行预览供核对，动作给触感/文字反馈。
   - 就地转交：一键生成含维度、时间范围（含口径）、金额、笔数、占比、负责人、已导出行数的
     交接文本，复制即可粘贴给负责人，不用回聊天窗口手打。

实现约束：
- 文件名与类名/函数名按模板原样（AdminQuerySpec.kt / AdminQueryDemo.kt / AdminQueryScreen.kt），
  只改 package 与 R 引用，不要改成中文名或自创名字。
- 不新增第三方依赖：柱状图用 Box + 比例高度自绘，CSV 用字符串拼接，不引图表库/CSV 库。
- minSdk < 26 时先说清 java.time 的处理方案（开 desugaring 或改 Calendar），口径不变：
  闭区间、含首尾、超限置灰。
- 用到 FlowRow 加 @OptIn(ExperimentalLayoutApi::class)；长按复制用 combinedClickable 要加
  @OptIn(ExperimentalFoundationApi::class)。
- 演示/联调阶段若用假数据，必须在页面与文档明示「模拟数据」，不许说成真实业务数据；
  接真实接口时把四个纯函数（过滤/聚合/CSV/交接话术）保留，只换数据源。
- 列表返回不许回顶部：选中态存 id（可保存），列表状态用可保存的 LazyListState。

验收（逐项汇报，附截图或录屏）：
- 批量模式下连改 10 个条件，累计请求只 +1；切即时模式后每次改动 +1。
- 折叠区有已选值时入口徽标数字正确；展开后能改能清。
- 六个时间档位都写明起止；超限档不可点且原因可见；起止倒置时查询禁用；查询后回显「共 n 天（含首尾）」。
- 全选 20 个部门时标签区只有 1 个聚合标签；选 4 个收成「部门 · 4」；选 2 个是 2 个独立标签；
  删任一标签命中数立刻变化；「摊开所有标签（反例）」对照能看出行数差异。
- 点任一柱子详情与明细同步变化；导出行数 = 明细笔数；切维度后选中态清空；未选中时无旧数据残留。
- 合体页九段结构齐全，标签区反映全部生效条件（含时间与部门聚合），导出内容 = 当前切片。
- 与模板的差异单列一节（例如未接真实接口、导出改成了写文件、阈值改成 5），没有写「无」。
```
