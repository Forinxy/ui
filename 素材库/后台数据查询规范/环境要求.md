# 后台数据查询规范 · 环境要求

> 基准以 `android/gradle/libs.versions.toml` 为唯一可信来源；本文件只列本模块**额外**需要注意的点。

## 1. 版本基准（示例 App 实测）

| 项 | 值 |
|---|---|
| JDK | 17 |
| compileSdk | 36 |
| minSdk | **26**（本模块硬要求，见下） |
| targetSdk | 35 |
| Kotlin | 2.3.10 |
| AGP | 8.7.3 |
| Compose BOM | 2024.10.01 |
| Gradle | 8.11.1 |

## 2. 为什么 minSdk 必须 ≥ 26

本模块用 `java.time.LocalDate` 与 `java.time.temporal.ChronoUnit` 计算时间区间
（快捷档位起止、含首尾天数、保留期置灰、自定义起止校验）。

- `minSdk ≥ 26`：直接可用，无需任何额外配置（示例 App 即此情况）。
- `minSdk < 26`：必须开启 core library desugaring，否则运行期崩：
  ```kotlin
  compileOptions { isCoreLibraryDesugaringEnabled = true }
  dependencies { coreLibraryDesugaring("com.android.tools:desugar_jdk_libs:2.x.x") }
  ```
  或改用 `java.util.Calendar` 自行实现同样的区间计算（口径不能变：闭区间、含首尾、超限置灰）。

## 3. 新增依赖

**无。** 本模块只用 Compose BOM 内已有工件：

| 用到的能力 | 来源工件 |
|---|---|
| `FlowRow`（条件芯片自动换行） | `androidx.compose.foundation:foundation-layout` |
| `horizontalScroll` / `clickable` / `background` / `clip` | `androidx.compose.foundation:foundation` |
| `LazyColumn` / `LazyListState.Saver` | `androidx.compose.foundation:foundation` |
| `Text` / `Surface` / `MaterialTheme` / `OutlinedTextField` / `TextButton` | `androidx.compose.material3:material3` |
| `BackHandler`（详情页返回） | `androidx.activity:activity-compose` |
| 剪贴板 / 触感反馈 | `androidx.compose.ui:ui`（`LocalClipboardManager`、`LocalHapticFeedback`） |
| 协程 `delay`（模拟查询耗时） | `kotlinx-coroutines`（随 Compose 传递依赖） |

不需要网络库、图表库、CSV 库：柱状图用 `Box` + 比例高度自绘，CSV 用 `buildString` 拼接。

## 4. 需要的注解开关

| 注解 | 用在哪 | 不加会怎样 |
|---|---|---|
| `@OptIn(ExperimentalLayoutApi::class)` | 使用 `FlowRow` 的预览（Q01 / Q03 / Q05） | 编译报错：experimental API 未 opt-in |
| `@OptIn(ExperimentalFoundationApi::class)` | 详情页 `combinedClickable`（点按展开 + 长按复制）与目录卡片 | 编译报错：experimental API 未 opt-in |

本模块**不使用** `ModalBottomSheet` 等 Material3 实验组件，因此不需要
`@OptIn(ExperimentalMaterial3Api::class)`。

## 5. 权限与隐私

| 项 | 要求 |
|---|---|
| 网络权限 | **不需要**（数据本地生成，不请求网络） |
| 存储权限 | **不需要**（导出 = 复制到剪贴板，不写文件） |
| 剪贴板 | 使用系统剪贴板写入提示词 / CSV / 交接话术，无需权限，但要在 UI 上明示「已复制」 |
| 触感反馈 | `HapticFeedbackType.LongPress`，无需权限；系统关闭触感时自动无反馈，不要因此报错 |

宿主若把「导出」改成写文件/下载，需自行申请对应存储权限并在 UI 明示保存路径——
那时本模块的环境要求不再适用，按宿主项目的存储方案走。

## 6. 对仓库内组件的依赖（可替换）

| 组件 | 用途 | 宿主没有时怎么办 |
|---|---|---|
| `GlassCard` | 详情页/部门选择器的卡片容器 | 换成 `Surface(shape = ..., color = ...)`，不影响规范逻辑 |
| `SectionTitle` | 分区小标题 | 换成 `Text(style = MaterialTheme.typography.labelLarge)` |

除这两个外，本模块自带全部原子控件（`QChip` / `QTag` / `QButton` / `QSwitchRow` / `QNote` /
`QMono` / `QRowLine`），**故意不复用全局控件**，避免与宿主的控件签名耦合导致抄了编不过。

## 7. 已知平台差异

- **深色/浅色**：全部颜色走 `MaterialTheme.colorScheme`，两套主题都可读；
  柱状图未选中态用 `primary.copy(alpha = 0.22f/0.55f)`，深色下对比度足够。
- **O神（Miuix）模式**：`SectionTitle` 会自动切成 Miuix 分组小标题样式，其余布局不受影响。
- **字体缩放**：柱状图下的维度名与笔数用 9sp 固定小字，系统字体放大到最大时可能截断
  （已设 `maxLines = 1`），需要更强适配时改用 `autoSize` 或把维度名移到柱顶。
- **减少动效**：本模块没有位移动画，只有 loading 文案切换，天然满足「减少动效」要求。
